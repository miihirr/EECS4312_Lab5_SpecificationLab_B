VS Code: To create a Python virtual environment using the terminal in Visual Studio Code, follow these steps:

1. Use the **Python: Create Terminal** command to create a new terminal with your Python environment activated.



Show in Command Palette



2. Alternatively, use the **Python Envs: Create Python Terminal** command for more environment options.



Show in Command Palette



3. Then, in the terminal, run the command to create a virtual environment:
   - For Venv: `python3 -m venv venv`
   - For Conda: `conda create --name myenv python`

4. Activate the virtual environment:
   - For Venv on macOS: `source venv/bin/activate`
   - For Conda: `conda activate myenv`

To ensure your Python environment automatically activates in all new terminals, enable the **python.terminal.activateEnvironment** setting:



Show in Settings Editor
